# Crafter Notes

Crafter Notes is a quiet companion notebook for crafting-heavy experiences.

It helps users quickly capture and retrieve crafting knowledge while playing games, without forcing them into forms, databases, or heavy productivity systems.

Primary audience:
- cozy game players
- crafting-focused gamers
- players juggling multiple save files or worlds
- players who use their phone beside a desktop, console, or handheld

Secondary audience:
- recipe keepers
- hobby crafters
- gardeners
- DIY users

---

# Product Essence

Crafter Notes is not:
- a productivity app
- a game wiki clone
- a database builder
- a dashboard
- a task manager

Crafter Notes is:
> a contextual memory layer for crafting.

The app should feel like a small workbench beside the game.

---

# Core Product Model

Home is for active play.

The core hierarchy:

1. Quick Note
2. Pinned Notes
3. Search
4. Folders
5. Entries

---

# Emotional Goal

The app should feel:
- calm
- lightweight
- tactile
- intentional
- editorial
- quietly useful

The interface should disappear behind the user’s thoughts.

---

# Core Philosophy

## 1. Quick Capture First

The user often opens the app mid-session.

The app should help them jot something down before they forget.

Quick Note is the primary home interaction.

## 2. Pinned Context Second

Gamers often craft multiple things at once.

Pinned notes act as active references:
- recipes
- upgrade costs
- gift lists
- current goals
- crafting chains

Pinned notes should be visible from Home.

## 3. Entries Are Memory

Entries are saved notes users want to keep.

Entries may belong to folders, but folders should not dominate the app.

## 4. Folders Are Worlds

Folders separate contexts.

Examples:
- Stardew Valley
- Travellers Rest
- Coral Island
- Personal Recipes

Folders are not the homepage.
They are an index.

## 5. Structure Emerges Naturally

The app may suggest craft-specific sections, but should never impose them.

The user should always be allowed to simply write.

---

# Craft Sections

V1 craft sections:

- Ingredients
- Use
- Details
- Checklist
- Tips

These sections are optional.

Avoid turning sections into forms.

---

# Pixel Personality

Crafter may use a tiny monochrome pixel mascot and pixel icon set to add warmth.

This personality should remain:
- quiet
- lightweight
- functional
- secondary to writing

The mascot and icons should never turn the app into a game UI.

---

# Anti Goals

Do NOT become:
- Notion
- Obsidian
- a database builder
- a wiki scraper
- a productivity operating system
- a gamified habit tool

The app should remain:
- lightweight
- focused
- minimal
- writing-first

---

# Product Taste

The design language should feel closer to:
- editorial layouts
- stationery
- field notebooks
- cafe menus
- packaging systems
- quiet Japanese/Korean product sensibility

Than:
- startup dashboards
- gaming overlays
- anime interfaces
- heavy SaaS screens

This is not a themed “Japanese app.”
The restraint comes from spacing, typography, pacing, and reduction.

---

# Monetization Philosophy

V1 should feel generous and indie.

Recommended model:
- Free: limited notes
- Plus: one-time unlock for unlimited notes
- Ko-fi: optional support

Avoid subscription until there is ongoing value such as sync, AI, OCR, or cloud backup.

---

# AI Workflow Philosophy

AI is used for orchestration and acceleration, not for replacing intentional design decisions.

All generated work should be evaluated against:
- restraint
- clarity
- interaction quality
- emotional coherence
- usefulness during actual gameplay
